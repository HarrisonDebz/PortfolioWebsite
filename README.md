# Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my projects, skills, and experience. Designed with a clean UI, smooth animations, and a focus on clarity and performance.

##  Features
- Responsive design for desktop, tablet, and mobile
- Dark-themed modern UI
- Smooth scroll and subtle animations
- Projects showcase with links and descriptions
- About section highlighting skills and background
- Contact section / social links
- Fast load times and clean structure

##  Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Styling:** CSS / Tailwind CSS
- **Animations:** CSS Animations / JavaScript  
- **Deployment:** GitHub Pages
