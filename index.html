Featured Projects

Recipe App

The Recipe App is a cross-platform application built using .NET MAUI, designed to help users store, browse, and manage their favorite recipes in one place. Built on .NET MAUI (Multi-platform App UI), the app runs natively on Android, iOS, Windows, and macOS, all from a single codebase written in C# and XAML. This project demonstrates my ability to design responsive UI, implement smooth navigation, and leverage modern development tools to create seamless experiences across multiple platforms.

C# • XAML • HTML:5

EventPulse

EventPulse is a campus-focused event management app built with .NET MAUI. A cross-platform framework that lets us ship native apps for Android, Windows, and more from one codebase, to fix how university events are handled - from scattered WhatsApp posters and word-of-mouth chaos to a centralized, smart event hub.

C# • XAML • HTML:5
