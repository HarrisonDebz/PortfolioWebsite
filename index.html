Recipe App

The Recipe App is a cross-platform application built using .NET MAUI, designed to help users store, browse, and manage their favorite recipes in one place. Built on .NET MAUI (Multi-platform App UI), the app runs natively on Android, iOS, Windows, and macOS, all from a single codebase written in C# and XAML. This project demonstrates my ability to design responsive UI, implement smooth navigation, and leverage modern development tools to create seamless experiences across multiple platforms.

C# • XAML • HTML:5

EventPulse

EventPulse is a campus-focused event management app built with .NET MAUI. A cross-platform framework that lets us ship native apps for Android, Windows, and more from one codebase, to fix how university events are handled - from scattered WhatsApp posters and word-of-mouth chaos to a centralized, smart event hub.

C# • XAML • HTML:5

Website Vulnerability Scanner

WebVal Analyzer is a web-based vulnerability scanning tool designed to help developers and site owners identify common security issues in their websites. Built with JavaScript and modern frontend technologies, the tool analyses input URLs for potential threats. The project reflects my growing focus in cybersecurity, blending practical web dev skills with vulnerability detection logic.

JavaScript • Node.js • AXIOS • JSDOM

CAT - Attendance Tracker

The Class Attendance Tracker (CAT) is a production-grade mobile solution built with .NET MAUI and Supabase. It automates academic management with real-time data sync, role-based access for lecturers and students, and intuitive dashboard reporting. It solves the complexity of manual attendance with a single, secure digital hub.

.NET MAUI • C# • Supabase • XAML
